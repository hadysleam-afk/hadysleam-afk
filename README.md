# 💫 About Me:
**Backend developer** and third-year Physics & Computer Science student at the Faculty of Science, Zagazig University.

I build server-side applications: REST APIs with Node.js/Express and PHP/Laravel, SQL database design, authentication, and ORM workflows with Prisma. I also work with React and TypeScript on the frontend, and with Python, FastAPI and Docker for services and deployment.

Open to backend internships and junior backend roles.

## 🚀 Featured Project:
### [SolarMind AI](https://github.com/hadysleam-afk/SolarMind)
A full-stack solar panel inspection and PV physics platform. Node/Express/Prisma REST API, React + TypeScript web client (English and Arabic), and a FastAPI/PyTorch service. Image classification currently runs in demo mode until model weights are added.
